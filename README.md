# Santa Rosa Malhas & TexMalha - Painel Operacional

Este repositório contém a aplicação web desenvolvida em React, TypeScript e Tailwind CSS para fornecer um Terminal de Operação para a **Santa Rosa Malhas** e a **TexMalha**.

## 🚀 Funcionalidades

- **Acesso Duplo Integrado**: Terminal dedicado e estilizado para as duas confecções (Santa Rosa Malhas e TexMalha).
- **Visualização de Planilhas em Tempo Real**: Integração nativa e interativa com as planilhas do Google Sheets.
- **Função de Impressão Direta**: Botão inteligente que exporta e gera a impressão direta das linhas 1 a 99 da planilha de produção da TexMalha no formato PDF oficial de impressão.
- **Identidade Visual Polida**: Logos oficiais incorporados e layout totalmente responsivo para desktops, tablets e celulares.

## 🛠️ Tecnologias Utilizadas

- **React 18** com **TypeScript**
- **Tailwind CSS** para estilização utilitária e design responsivo
- **Vite** para empacotamento ultrarrápido
- **Lucide React** para iconografia moderna e consistente
- **Motion (Framer Motion)** para transições de tela fluidas e micro-interações

## 📦 Implantação (Deployment)

Esta aplicação está totalmente configurada e pronta para publicação no **Vercel** com suporte a URLs amigáveis e roteamento SPA (Single Page Application) através do arquivo `vercel.json` já presente no projeto.

### Como tornar este repositório público no GitHub

Como este ambiente de desenvolvimento não possui acesso para alterar diretamente as configurações de privacidade da sua conta do GitHub, você pode tornar o repositório público em poucos passos simples diretamente na plataforma do GitHub:

1. Acesse o seu repositório no **GitHub**.
2. Clique na aba **Settings** (Configurações) no topo da página do repositório.
3. Role a página principal até o final, na seção **Danger Zone** (Zona de Perigo).
4. Localize a opção **Change repository visibility** (Alterar visibilidade do repositório).
5. Clique em **Change visibility** e selecione **Make public** (Tornar público).
6. Confirme a ação digitando o nome do repositório ou por meio de verificação em duas etapas, se solicitado.
